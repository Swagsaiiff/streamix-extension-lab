# Bollyflix Streamix Native Extension

Streamix-native provider extension for Bollyflix, ported from the CloudStream CSX provider repository.

## Metadata
- **Extension ID**: `org.streamix.provider.bollyflix`
- **Version**: `1.0.0`
- **Languages**: Hindi (`hi`), English (`en`)
- **Content Types**: `movie`, `series`, `anime`
- **Upstream Source**: [CSX / BollyflixProvider.kt](https://github.com/SaurabhKaperwan/CSX)
- **Original Author**: `megix` / Saurabh Kaperwan
- **License**: GNU General Public License v3.0 (GPLv3)

## Capabilities
- Dynamic domain resolution via `urls.json` (`bollyflix` key)
- Search parsing of post cards (`<article>`)
- Cinemeta / Stremio metadata integration via IMDb link resolution
- Multi-season & episode parsing
- GDFlix / FastDL / Sidexfee bypass extraction
