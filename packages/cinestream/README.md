# CineStream Streamix Native Extension

Streamix-native provider extension for CineStream, ported from the CloudStream CSX provider repository.

## Metadata
- **Extension ID**: `org.streamix.provider.cinestream`
- **Version**: `1.0.0`
- **Languages**: English (`en`), Hindi (`hi`)
- **Content Types**: `movie`, `series`, `anime`
- **Upstream Source**: [CSX / CineStreamProvider.kt](https://github.com/SaurabhKaperwan/CSX)
- **Original Author**: `megix` / Saurabh Kaperwan
- **License**: GNU General Public License v3.0 (GPLv3)

## Capabilities
- Cinemeta & Stremio high-performance catalog search (movie + series)
- Complete structured metadata parsing with IMDb rating, genres, poster, backdrop, and cast
- Complete multi-season episode catalog with titles, overviews, thumbnails, and release dates
- Multi-source resolver pipeline
